# EduTrack

Repositorio para las aplicaciones independientes de EduTrack.

## Aplicación web

La aplicación web con Django, PostgreSQL, Docker y sus instrucciones de instalación están en [edutrack-web/](./edutrack-web/). Consulta su [README](./edutrack-web/README.md).

## Aplicación desktop

La aplicación de escritorio offline, hecha con Python y QML, está en [edutack-desktop/](./edutack-desktop/). Consulta su [guía de instalación y sincronización](./edutack-desktop/README.md).
